# Portfólio

Site pessoal feito para reunir meus projetos, minha formação e algumas coisas que venho aprendendo com desenvolvimento web.

**Acessar:** https://soars1.github.io

## Sobre

O site é estático e foi desenvolvido com HTML e CSS, sem frameworks. A ideia é manter a navegação simples e o conteúdo fácil de encontrar.

Tem seções de trabalhos, sobre mim, acessibilidade, formação e contato, além de uma página separada para cursos.

## Acessibilidade

Alguns cuidados que adotei:

- Link para pular direto ao conteúdo;
- Navegação por teclado e foco visível;
- Estrutura com elementos semânticos;
- Textos e links identificáveis;
- Layout adaptável a diferentes tamanhos de tela.

Ainda estou estudando e revisando esses pontos. Isso não significa que o site já passou por uma auditoria completa de acessibilidade.

## Como executar

Não precisa instalar dependências. Basta abrir o `index.html` no navegador.

Para testar com um servidor local, na pasta do projeto:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Estrutura

- `index.html` — página principal;
- `styles.css` — estilos do site;
- `cursos/` — página de cursos e formação.
